#  ElevenLabs ai voice 🎙️

VoiceForge AI is an AI text-to-speech web application that converts written text into natural-sounding speech.

## Features

- Text to Speech
- Hindi and English voice support
- Multiple voice options
- Speed control
- Audio preview
- Audio download
- Mobile responsive design
- Secure ElevenLabs API integration
- Future-ready architecture for user accounts and credits
